## Tech Stack (this site)

- Pure HTML/CSS/JS — no framework, no build step

## Running Locally

```bash
git clone https://github.com/yxshas565/yashas-portfolio.git
cd yashas-portfolio
open index.html   # or just double-click it
```

No build step, no dependencies — it's a single static HTML file.

## Deployment

This repo is served directly via **GitHub Pages** from the `main` branch root. Any push to `main` updates the live site at [yxshas565.github.io/yashas-portfolio](https://yxshas565.github.io/yashas-portfolio/) within a minute or two.
