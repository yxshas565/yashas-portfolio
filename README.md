## Featured Work

### EdgeDaemon / MechGuard

**EdgeDaemon** is the venture context for my ongoing work on AI assurance. **MechGuard** is its research/product system for monitoring internal model behavior across training and deployment, with a focus on mechanistic and activation-level signals.

### Selected Projects

- **Autonomous ML Pipeline Orchestration Agent** — multi-agent system that turns a plain-English GitLab issue into an ML pipeline workflow.
- **Sunrise AI Voice Agent** — AI voice-agent system for outbound conversations, structured lead extraction, webhooks, and dashboard workflows.
- **MilletDataNet** — computer-vision system combining model training, provenance APIs, a dashboard, and simulated IoT data flow.
- **Weather Risk Forecasting** — data-science and forecasting system built around large-scale weather observations, feature engineering, forecasting, uncertainty analysis, and visualization.
